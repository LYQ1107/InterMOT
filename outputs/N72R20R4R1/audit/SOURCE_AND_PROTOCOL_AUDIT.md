## Mechanism findings

The original counterfactual miner used one target per sequence, sampled every five frames and applied a strength-0.5 residual. It did not fix an edge. An unchanged solver outcome cannot satisfy its beneficial-label condition. This explains a supervision mechanism, not the absence of real-world correction opportunities.

The exact pairwise source score uses appearance, predicted IoU, native core 0.5, gap penalty, native bonus 3 and optional positive bonus 5, with sequential float32 rounding. Decomposition reproduces that exact order. Native activation is observed in every development sequence. Positive-history and hard-negative activation counts are zero in these actual rollouts: the source initializes empty constraint sets and a human click does not populate them. Synthetic tests activate them only to verify preservation; synthetic examples are not training evidence. Positive-history reliability therefore requires an identifiability audit, not an invented learning result.

The new force-edge solver removes the fixed candidate row and target public column, solves all remaining ownership with explicit NONE and reconstructs the complete result. REJECT removes the target column. Every remaining state, birth and loss must commit this result. Hard negatives remain immutable; native and positive continuity are soft evidence.
